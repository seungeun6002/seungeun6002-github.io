# lily's favorite

여행 · 타로 · 부동산 재테크 — 좋아하는 것들을 모아둔 미니 홈페이지.

## 구성
- `index.html` — 페이지 뼈대
- `style.css` — 디자인 (스마트폰 우선, 다크모드 지원)
- `script.js` — 메뉴와 내용 (`SITE` 부분을 고치면 내용이 바뀜)
- `assets/` — 사진 ([Pixabay](https://pixabay.com), 출처는 `assets/credits.json`)

## GitHub Pages로 공개하기
1. 이 저장소의 **Settings → Pages**로 이동
2. Source: **Deploy from a branch**, Branch: **main / (root)** 선택 후 Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 접속
